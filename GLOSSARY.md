# Bookmark Manager

A self-hosted app where one person keeps a grid of saved URLs and opens them from any device.

## Language

**Bookmark**:
A saved URL with a title.
_Avoid_: Link, favorite, mark

**Start page**:
The page at the app root. It shows the grid of bookmarks. The user adds, renames, and deletes bookmarks here.
_Avoid_: Dashboard, home page, new-tab page

**Title**:
The name of a bookmark, as shown on the start page.
_Avoid_: Name, label
